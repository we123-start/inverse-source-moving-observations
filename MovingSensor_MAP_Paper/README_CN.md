# 移动传感器抛物型反源问题：论文复现代码

本仓库仅保留论文中的四类源形状和每种形状的三个实验：**圆形、风筝形、四叶形、花生形**，共 12 个 MATLAB 入口。正问题采用极坐标 Q2 有限元与后向 Euler 格式；反演采用带几何约束的 MAP/SQP 方法（固定初值、一次 SQP 和可行下降时接受第二次 SQP 细化）。不含 MCMC、独立在线演示、旧固定时间方案或预先计算的 MAP 解。

## MATLAB 使用方法

需要 MATLAB + Optimization Toolbox（`fmincon`）。先切换到本仓库根目录：

```matlab
clear functions
rehash
CHECK_PROJECT

% 单个论文算例：花生形状的固定位置对照
[out,files] = RUN_AND_SAVE_PAPER('PEANUT_EXP2','noisy',1);

% 从零运行全部 12 个实验并保存新结果
summary = RUN_ALL_AND_SAVE_PAPER('noisy',1);
assert(all([summary.results.completed]));
```

`<SHAPE>_EXP1` 为四阶段自适应重建，`<SHAPE>_EXP2` 为三个固定观测位置对照，`<SHAPE>_EXP3` 为三个预设双位置对照，`<SHAPE>` 为 `CIRCLE`、`KITE`、`FOURLEAF`、`PEANUT`。

## 观测时刻只有一套规则

`matlab/V16_ROUTE.m` 根据每次测量的通量决策移动方向，再根据实际航行时间和 `V16_NEXT_WINDOW.m` **递推计算下一观测窗口**，没有预先给定未来的窗口表。在固定论文噪声样本 `('noisy',1)` 下，时间窗口（网格下标，采样间隔 `1/400`）为：

| 形状 | 第一窗口 | 第二窗口 | 第三窗口 | 第四窗口 |
|---|---|---|---|---|
| 圆形、风筝形、四叶形 | [1,80] | [91,170] | [181,260] | [266,345] |
| **花生形** | [1,80] | [91,170] | [181,260] | **[265,344]** |

**花生形仅使用 `[265/400,344/400]`，不会再由主程序产生旧的第四窗口。** 每组完整实验有 320 个主要通量观测值；同一形状的自适应、固定位置及双位置对照使用相同时间及主要观测噪声。自适应路线另外使用 6 个辅助测量值，仅用于选择移动方向，不进入 MAP 似然项。低通量对照位置来自已知真解，仅用于合成实验公平对照。
